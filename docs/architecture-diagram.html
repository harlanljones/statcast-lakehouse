Statcast Lakehouse — Architecture

MLB Statcast → BigQuery lakehouse (BQML xWhiff) → Arrow IPC → GPU-rendered 3D trajectories

Warehouse

  • • bronze: raw, partitioned by ingestion_time, 90-day expiry
  • • fct_pitches: game_date partitions, clustered pitcher/batter/type
  • • ST_GEOGPOINT plate_location indexed at curation
  • • require_partition_filter on every table

Inference

  • • BQML BOOSTED_TREE_CLASSIFIER on swings only
  • • features: kinematics (v/a vectors), speed, spin, location
  • • batch inference: one partition per game day
  • • no model-hosting cost — inference = query scan

Client SLA

  • • <16 ms input-to-paint, 60–120 FPS locked
  • • zero JSON: Arrow IPC → zero-copy typed arrays
  • • trajectories recomputed client-side from 9 params
  • • slider filtering in the vertex shader, never in JS
